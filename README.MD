# Assetto Corsa Lua Apps
A repository containing a collection of (mostly) Lua apps for Assetto Corsa.
## Available apps
 - **SmoothAnims**: app that visually smoothens out steering and shifting animations.
 - **Time Control**: app that lets the user skip the time of day by 30 minutes with two neat buttons.
## How to install
**Method 1**: Content Manager

Drag and drop the .zip archive directly into Content Manager and click Install.

**Method 2**: Manual Installation

Extract the apps folder from the archive directly into your Assetto Corsa root directory.
